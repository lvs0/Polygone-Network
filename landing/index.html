Installer

# One-liner
curl -fsSL https://github.com/lvs0/Polygone-Network/releases/latest/install.sh | bash

# Ou depuis le code
git clone https://github.com/lvs0/Polygone-Network.git
cd Polygone-Network
cargo build --workspace --release

Démo en 60 secondes

# La démo complète E2E — chiffre, fragmente, route, déchiffre
polygone demo

# Le scénario guidé : message éphémère, vérification, mort
polygone premier-soir

# Vérifier l'absence : ce que ce nœud garde de toi
polygone verite

# Envoyer/recevoir sans réseau (local)
polygone envoyer -d <clef> "message" > wire.txt
polygone recevoir wire.txt

Cryptographie

  • ML‑KEM‑1024 (FIPS 203) — encapsulation de clé post‑quantique
  • ML‑DSA‑65 (FIPS 204) — signature post‑quantique par message
  • AES‑256‑GCM — chiffrement symétrique avec nonce frais
  • BLAKE3 — hachage rapide, intègre résistant
  • Shamir 4‑of‑7 — aucun nœud ne voit le message en entier
  • Horodatage ±300 s — protection anti‑rejeu
  • Zeroize — effacement mémoire après chaque opération

Philosophie

  • Pas de compte. Pas de télémétrie. Pas de cloud sync.
  • Le relay ne sait pas qui parle à qui. Il voit des fragments, pas des messages.
  • Rien n'est persisté. Chaque fragment meurt après le transit.
  • AGPL‑3.0 : toute redistribution doit publier le code source.
  • Post‑quantique aujourd'hui, pas demain.
  • Honesty‑first : le threat model dit ce qui est protégé, et ce qui ne l'est pas.
