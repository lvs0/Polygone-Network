Ce que cette console ne montre pas

  • Aucun contenu de message : le relais et la gateway ne le lisent pas.
  • Aucun compteur de trafic ni de fragments : la gateway ne les expose pas, donc la console affiche « — » au lieu d'inventer un chiffre.
  • Identité publique seulement : les clés secrètes restent dans le fichier local, jamais servies par l'API.
  • Réglages en lecture seule : les modifications passent par la CLI polygone.
  • Une gateway arrêtée ou injoignable laisse toutes les valeurs inconnues ; rien n'est simulé.

Démarrer la gateway : polygone-gateway --site-dir ./web.
