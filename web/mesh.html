    Ce que cet écran montre

    • Chaque appareil est une ancre appairée : clé publique ML-DSA-65 épinglée (TOFU).
    • « Actif » = vu dans les 5 dernières minutes (heartbeat). Ce n'est pas une connexion permanente.
    • Latence = mesure ping/pong réelle ; « — » tant qu'aucune mesure n'existe.
    • Révoquer retire l'approbation sur cet hôte : révocation locale, pas un CRL distribué.
    • Aucune topologie physique inventée : pas de graphe simulé, pas de CPU/RAM fictif par pair.
    • Gateway injoignable → valeurs inconnues ; rien n'est simulé.

    Appairer un appareil : POST /api/v1/pair/request puis /pair/accept, ou la CLI polygone.
